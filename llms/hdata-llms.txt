# HData

> HData is the AI-native operating system for energy regulation. It turns disconnected federal and state regulatory filings, dockets, and proceedings (FERC, EIA, state utility commissions) into standardized, citable, machine-readable data, paired with domain-specific AI trained on 20M+ citable documents and purpose-built tools for utilities, regulators, advocates, and large energy customers.

Founded in 2018 by Hudson Hollister. Industry: regulated energy / power & utilities. No public developer API is currently published; the platform is delivered as a SaaS application. This file is generated by the API Evangelist enrichment pipeline from the catalog.
